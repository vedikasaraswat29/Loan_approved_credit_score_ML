# Loan Approval Prediction using Machine Learning

## 📌 Overview
This project builds an end-to-end supervised machine learning pipeline to predict whether a loan will be approved or not.

## 🎯 Objective
To perform binary classification using multiple ML algorithms and compare their performance.

## ⚙️ Tech Stack
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib / Seaborn

## 📊 Project Workflow
1. Data Cleaning & Preprocessing  
2. Exploratory Data Analysis (EDA)  
3. Feature Engineering  
4. Model Building  
5. Model Evaluation  

## 🤖 Models Used
- K-Nearest Neighbors (KNN)  
- Logistic Regression  
- Naive Bayes  

## 📈 Evaluation Metrics
- Accuracy  
- Precision  
- Recall  
- F1 Score  

## 🧠 Key Learning
- Importance of feature engineering  
- Difference between precision & recall  
- Model comparison in classification problems
